# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Privacy Tool 🔒

This repository includes a comprehensive **Mac Privacy Tool** for protecting your MAC address and hardware serial number.

### Quick Access
- 📁 Location: `/privacy-tool`
- 📖 Full Documentation: [privacy-tool/README.md](privacy-tool/README.md)
- 🚀 Quick Start: [privacy-tool/QUICKSTART.md](privacy-tool/QUICKSTART.md)

### Features
- MAC address randomization and spoofing
- Hardware serial number privacy protection
- Privacy monitoring and auditing
- Network interface management

### Installation
```bash
cd privacy-tool
./install.sh
sudo npm link
```

See the [privacy tool documentation](privacy-tool/README.md) for complete details.
